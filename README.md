# Aether AI

AI Workplace Productivity Assistant – Premium SaaS Edition

Build a modern, premium-quality responsive web application called "AI Workplace Productivity Assistant" that helps professionals automate daily workplace tasks using Artificial Intelligence.

The application should look and feel like a real enterprise SaaS product used by companies such as Microsoft, Notion, Slack, or Monday.com. It should be visually stunning, highly interactive, intuitive, and professionally designed.

Overall Design Style

Create a clean, elegant, futuristic interface with:

- Modern SaaS dashboard

- Glassmorphism effects on cards

- Soft shadows and smooth rounded corners

- Beautiful gradients

- Premium typography

- Consistent spacing

- Professional iconography

- Smooth animations and transitions

- Hover effects on every interactive component

- Light and Dark Mode toggle

- Fully responsive design for desktop, tablet, and mobile

Layout

Include:

- Professional collapsible sidebar

- Animated navigation

- Top navigation bar

- User profile section

- Search bar

- Notifications icon

- Dashboard overview

- Interactive cards

- Statistics widgets

- Activity timeline

- Quick actions section

Dashboard

Display professional analytics including:

- Emails Generated

- Tasks Completed

- Meetings Summarized

- Research Requests

- AI Conversations

- Productivity Score

- Weekly Performance Chart

- Recent Activity Feed

Use attractive charts, progress bars, badges, and KPI cards.

---

Core AI Features

1. Smart Email Generator

Allow users to generate professional emails based on:

- Purpose

- Tone

- Audience

- Length

Support tones such as:

- Professional

- Friendly

- Persuasive

- Formal

- Casual

- Apologetic

- Confident

Support audiences such as:

- Client

- Manager

- HR

- Team

- Supplier

- Customer

Include:

- Generate button

- Copy button

- Regenerate button

- Clear button

- Loading animation

---

2. Meeting Notes Summarizer

Allow users to paste meeting notes.

Generate:

- Executive Summary

- Key Discussion Points

- Decisions Made

- Action Items

- Responsible Person

- Deadlines

- Risks

- Follow-up Tasks

Display results in beautifully designed cards.

---

3. AI Task Planner

Allow users to enter:

- Tasks

- Deadlines

- Priority

- Estimated duration

Generate:

- Daily Schedule

- Weekly Planner

- Priority Matrix

- Time Blocking Suggestions

- Productivity Tips

Visualize tasks using Kanban-style cards or timeline layouts.

---

4. AI Research Assistant

Allow users to ask research questions.

Generate:

- Summary

- Key Insights

- Recommendations

- Pros & Cons

- Risks

- Actionable Next Steps

Include citation placeholders and confidence indicators.

---

5. AI Workplace Chatbot

Create an attractive AI chat interface with:

- Chat bubbles

- Typing animation

- Suggested prompts

- Conversation history

- Clear conversation button

- Auto-scroll

- Timestamp for each message

---

Prompt Engineering

Design structured prompts internally for every AI feature.

Each prompt should clearly define:

- Role

- Goal

- Context

- Constraints

- Output Format

Ensure AI outputs are professional, concise, well-structured, and business-ready.

---

User Experience

Include:

- Loading skeletons

- Animated loaders

- Toast notifications

- Success messages

- Error handling

- Input validation

- Helpful tooltips

- Empty states

- Smooth page transitions

Every button should provide visual feedback.

---

Accessibility

Ensure:

- Keyboard navigation

- High color contrast

- Readable typography

- Accessible labels

- Responsive layouts

---

Responsible AI

Display the disclaimer prominently:

"AI-generated content may require human review."

Include a short Responsible AI section explaining:

- AI may produce inaccurate information.

- Users should verify important outputs.

- Sensitive information should not be shared.

---

Technology

Generate a production-quality prototype using modern web technologies.

Structure the project professionally with reusable components and clean code.

---

Visual Theme

Use a premium blue, purple, and cyan gradient palette with subtle animations, modern icons, elegant illustrations, and polished micro-interactions. The design should immediately impress recruiters and judges while remaining clean, fast, and easy to navigate.

The final result should resemble a polished commercial SaaS application rather than a simple student project, with a strong focus on professionalism, usability, and visual excellence.
